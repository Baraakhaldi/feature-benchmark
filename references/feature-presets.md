# Feature presets

Starting points only. Pre-fill questions from them, then adapt to the user's needs. Benchmark examples are suggestions to verify on every run (products change); always add direct competitors the user names.

| Feature | Flow steps to walk | States to capture | Typical top needs | Best-in-class to consider |
|---|---|---|---|---|
| Search | Entry point → type → suggestions → results → filter/sort → open item → back | Empty box, suggestions, results, no results, typo, second language, loading | Fast, forgiving of typos, relevant first results, filters keep context | Amazon, Airbnb, Algolia demos, Notion, Linear, Spotify |
| Filters and sort | Open filters → pick → apply → see count → clear → share URL | Default, many selected, zero results, mobile sheet | Live counts, easy reset, filters in the URL, mobile-friendly | Zalando, Booking.com, Airbnb, IKEA |
| Onboarding / sign-up | Landing → sign-up choice → details → verify → first-run setup → first success | Social vs email, validation errors, verification wait, skip, return later | Few fields, value before sign-up, clear progress, easy to skip | Duolingo, Notion, Canva, Revolut, Headspace |
| Checkout | Cart → delivery → payment → review → (stop before pay) | Guest vs account, address errors, payment options, promo code, delivery costs | No surprise costs, guest checkout, local payments, trust cues | Shopify checkout, Apple Store, Amazon, IKEA |
| Booking / scheduling | Choose service → date/time → details → review → (stop before confirm) | No availability, time zones, reschedule, cancel policy | See availability fast, few steps, clear policy, calendar add | Calendly, Airbnb, OpenTable, Booksy, Cal.com |
| Product / item detail | Arrive → media → key facts → options → primary action | Out of stock, variants, long text, reviews | Key facts above the fold, clear price, good media | Apple, IKEA, Airbnb listing, Allbirds |
| Notifications and inbox | Trigger → notification → open → act → settings | Empty, many unread, grouped, muted | Relevant, controllable, deep links, not noisy | Slack, GitHub, Linear, LinkedIn |
| Dashboard / analytics | Land → key numbers → change range → drill down → export | Empty account, loading, error, large data | Answers the main question first, filters, export | Stripe, Vercel, Plausible, Shopify admin |
| Settings and account | Open → find a setting → change → save → undo | Unsaved changes, errors, dangerous actions | Easy to find, safe defaults, clear destructive actions | GitHub, Google Account, Linear, Apple |
| Chat / messaging / support | Open → start → send → receive → attach → end/rate | Offline agent, bot handoff, long wait, error | Fast answer, human handoff, history | Intercom, WhatsApp, Zendesk, Shopify Inbox |
| Sharing and invites | Share entry → choose people/link → permissions → send (stop) | Link copied, permission levels, external user | Clear permissions, one-tap copy, preview | Figma, Google Docs, Notion, Dropbox |
| Store / location finder | Entry → locate me or type → list/map → detail → directions | Location denied, no results, many pins | Near me, hours now, directions, filters | IKEA, Starbucks, Apple Store, Google Maps |
| Forms (contact, application) | Open → fill → validate → review → (stop before submit) | Inline errors, autosave, upload, long form | Few fields, inline validation, save progress | Typeform, Stripe forms, GOV.UK patterns |
| Pricing and plans | Land → compare → toggle billing → pick plan → (stop before pay) | Monthly vs yearly, currency, enterprise | Clear comparison, honest totals, FAQ | Linear, Notion, Figma, Vercel |
| Reviews and ratings | See summary → filter → read → write (stop before post) | No reviews, negative reviews, media reviews | Trustworthy, filterable, helpful first | Amazon, Booking.com, Airbnb, Trustpilot |

## Feature not on the list
Build a row the same way: walk it in the user's product (or describe the intended flow), list 5-8 flow steps and the states, propose needs from the user's words, and ask Research module E for best-in-class candidates.
